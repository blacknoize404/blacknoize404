## Proyectos Destacados

*   **Patriae**: El primer proyecto pionero enfocado en la reproducción del dialecto cubano mediante modelos de Procesamiento de Lenguaje Natural y tecnologías de síntesis de voz (*Text-to-Speech*), respaldado por el entrenamiento con corpus de datos a gran escala.
*   **[MathUtils Studio](https://github.com/blacknoize404/MathUtils-Studio)**: Aplicación de escritorio de matemáticas paso a paso (Windows y Linux). Explica derivadas, límites e integrales regla por regla mostrando el árbol de expresión de cada paso, resuelve álgebra con métodos seleccionables e incluye paneles para matrices, números complejos, estadística y EDOs.
*   **[BI.MathUtils](https://github.com/blacknoize404/BI.MathUtils)**: Una biblioteca de Java para computación matemática avanzada. Trata expresiones algebraicas como objetos de primera clase, álgebra lineal (matrices/vectores 2D/3D), geometría, estadística y árboles de expresiones evaluables. Es el motor simbólico detrás de MathUtils Studio.
*   **[MiniJWS](https://github.com/blacknoize404/MiniJWS)**: Un framework de servidor HTTP ligero y modular construido desde cero en Java 25. Incluye enrutamiento, middleware, servicio de archivos estáticos y extracción de metadatos de APKs de Android.
*   **[BI.Windows.Shell](https://github.com/blacknoize404/BI.Windows.Shell)**: Integración con la shell de Windows desde Java, sin código nativo propio (Foreign Function & Memory API de Java 25). Modo oscuro para la barra de título y menús clásicos, y el menú contextual nativo del Explorador con todos los verbos del sistema y extensiones de terceros.
*   **[Pingmaster](https://github.com/blacknoize404/Pingmaster)**: Monitor de escritorio para hosts y APIs (Windows, Linux y macOS —Intel y Apple Silicon—). Sondea un objetivo en intervalos configurables por HTTP, HTTPS, ICMP o ICMP nativo, dibuja la latencia en vivo y avisa al instante cuando el objetivo se cae. Vive en la bandeja del sistema, mide la velocidad de subida y bajada del adaptador elegido, compara varios hosts en la misma gráfica, exporta a CSV, lanza alertas de latencia con sonidos propios y se encoge en modos flotantes (widget y tira mínima) que quedan sobre las demás ventanas.
*   **[NetworkUtils](https://github.com/blacknoize404/NetworkUtils)**: Biblioteca de Java para monitorizar latencia de hosts y tráfico de red — pings programados (con ICMP nativo mediante la Foreign Function & Memory API), flujos observables e historial acotado. Es el motor de sondeo detrás de Pingmaster.
*   **Schedu**: Aplicación multiplataforma para la gestión de horarios escolares y agenda personal, equipada con actualizaciones automáticas desde la nube.
*   **Dímelo**: Plataforma web diseñada para mejorar la visibilidad y accesibilidad de los negocios locales, cerrando la brecha entre propietarios y clientes mediante la digitalización.
*   **[Mi Cuenta Nauta](https://micuentanauta.github.io)**: Aplicación para Windows que simplifica la interacción con los servidores de ETECSA, gestionando sesiones de internet de forma segura e intuitiva.
*   **[Godot Audio Tools](https://github.com/blacknoize404/Godot-Direct-Audio-Input-Recorder-and-WAV-24-bits-Tools)**: Soluciona problemas de lag en Godot 4.6 accediendo al buffer de audio de bajo nivel para grabación estable de 24 bits.
*   **[PersistenceUtils](https://github.com/blacknoize404/PersistenceUtils)**: Módulo Java para simplificar la persistencia de datos mediante serialización avanzada.
*   **Colabs / Contribuciones**: Rembg (IA Generativa para eliminar fondos).

## Recursos Académicos y de Aprendizaje

Esta sección está dedicada a compartir el conocimiento técnico detallado detrás de mis desarrollos principales, ideal para estudiantes y desarrolladores curiosos.

### **[Aprende Protocolo HTTP y Arquitectura de Software con MiniJWS](https://github.com/blacknoize404/MiniJWS/tree/master/docs)**

MiniJWS, a parte de servir como un servidor funcional, fue construido como una iniciativa educativa. En su documentación, los principiantes pueden aprender:

1.  **Cómo funciona el estándar HTTP/1.1** desde cero, sin depender de librerías externas.
2.  **Decisiones de Diseño de Software:** Por qué se eligen ciertas clases de Java, patrones de diseño y estructuras de datos.
3.  **Concurrencia:** Implementación de *thread-pools* para gestionar múltiples conexiones.
4.  **Desmitificación del Middleware:** Cómo se construyen las características de seguridad (CORS, Rate Limit) y rendimiento (Gzip).

Es un recurso excelente para ver conceptos de redes y programación de nivel universitario aplicados en un proyecto del mundo real.
